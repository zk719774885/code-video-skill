# 爆款拆解：抖音 Claude 视频（2026-10，5 条逐帧分析）

样本：《运气的形状》（Iwanau，61 万赞）、《opus家族史》、「让 opus5.5 炫技」showreel、《定风波》苏轼、JellyPop「389 条提示词拆 3 个模板」。
方法：1080p 原片每 2 秒抽帧拼联系表 + 转场处每秒 3–6 帧连拍 + 语音转写 + 拍点比对。

## 一、"真实感"到底从哪来（三条路线）
| 路线 | 代表作 | 做法 |
|---|---|---|
| **A. AI 生图当背景，代码叠动画** | 《opus家族史》 | 每个时代一张生成图（岩画洞穴、海底沉船、智慧宫细密画、织布机、雪夜神社浮世绘、椋鸟群晚霞），**画风跟着时代换**；代码只负责叠在上面的东西：粒子拼字、打字机纸上逐字打出、迷宫老鼠、围棋落子、族谱树生长、光斑与飘落花瓣。背景慢推（Ken Burns）+ 叠化。评论区作者也承认画面是"调的其他模型"。 |
| **B. 纯代码，但每个物件都做"实物质感"** | 《运气的形状》 | 深棕黑底 + 暗角 + 颗粒；骰子/距骨是 3D 渲染的实物；羊皮纸文件、木纹地板；所有"数据"都是**真实模拟**（高尔顿板落珠堆出正态、布丰投针算出 π、摸球曲线收敛），观众看到的是物理过程不是图表。 |
| **C. 离线 3D / 重着色器** | 炫技 showreel、《定风波》 | showreel 字幕直接写了技术栈：**Blender 5.2 + Bullet 刚体 1700 颗 + Cycles 路径追踪 + 物理时间变速 1×→0.12×→1×（子弹时间）**；GLSL 百叶窗投影+雨滴阴影+体积烟；侵蚀地形+大气散射+水面反射+2.39:1 宽银幕+镜头光晕；20 万粒子 WebGL2；Mandelbulb。《定风波》是 Three.js 场景：汉字立方体海、3D 汉字立在水面、雨夜竹林里的蓑衣人、水墨月夜海面。 |

结论：我们现在的片子输在**没有路线 A**（没有任何写实图像素材），以及路线 B/C 的"实物感"做得不够（物件是扁平矢量，不是有材质有光的东西）。

## 二、转场与特效清单（逐帧确认过的）
- **叠化为主，硬切很少**：0.6–1 秒交叉溶解，前一幕的大标题在新背景上淡出（OPUS → 海底）。
- **字形变形**：同一圆框里阿拉伯文 → 模糊溶解 → 拉丁文 Algoritmi → "algorithm 算法"。
- **粒子聚字 / 散字**：墨点云聚成"苏轼"、金色光点聚成"OPUS"、片尾"干就完了"墨点炸开。
- **年份滚轮计数器**：左上角年份像里程表一样逐位滚动（0000→1100→1383→1494），每幕一个年份 + 地点小字，是贯穿全片的"时间锚"。
- **无限推镜 / 穿越**：镜头推进字海、穿过"大"字进入下一幕；showreel 用运动模糊快推接场。
- **画中画 → 时间线**：showreel 后段把前面所有风格塞进一个"剪辑软件界面"（时间线、调色轮、示波器、混音推子），用"制作过程"本身当内容。
- **环境粒子常驻**：飘落花瓣、雪、雨、浮尘、光斑——几乎每个镜头都有一层慢速粒子，画面永远"在呼吸"。
- **光**：体积光（水下光柱）、台灯光锥、烛光、Drop 处一闪的星芒。

## 三、版式与叙事
- **无配音**，全靠字幕（4 条展示片都没有人声）。字幕：底部居中，逐字打出，关键词金色/红色高亮，下面一行小号英文斜体翻译。
- **四角信息层**：左上年份+地点，右上文献出处（书名 + 红色印章），右下作者水印；showreel 四角是取景框 + 时码 + 技术说明。
- **首尾呼应**：结尾回到开头的物件，片名再出现一次。《运气的形状》以骰子开场，结尾回到 2026 年的一颗骰子，片名重现；《opus家族史》以岩壁手印开场，结尾是雨夜窗前的笔记本屏幕，再叠化回岩壁手印，落版「Claude Opus 5.5 你的下一件作品」。
- **每幕一句话，一个物件**：一幕只讲一件事，主体物件居中，字幕一句。2 分钟片约 25–40 幕，每幕 3–6 秒。
- **配乐做骨架，不严格卡拍**：实测剪点落在拍点上的比例与随机相当，叠化跟着**乐句**走而不是每一拍。（与小冯四步法的"踩重拍"互补：知识片按乐句，炫技/快剪片按拍。）

## 四、提示词层面（awesome-opus5-5-videos，703 条）
- 技术栈统计：Three.js 出现在 192 条，Remotion 98 条，HyperFrames 24 条，Blender 16 条，ElevenLabs 13 条；README 精选 100 条的标签以 Canvas / SVG+GSAP / GLSL / Three.js 为主，少数标 "AI image"。
- JellyPop 三模板（可叠用）：
  1. **拉高水准**：制作一个【时长】的【视频类型】，展现你作为【顶尖角色】的卓越才能，要达到【代表作水准】，尽情发挥。
  2. **推动变化**：制作一支【时长】的短片，讲【主题】从【起点】一路发展到【终点】，每一段都换一种截然不同的画面风格。
  3. **统一画面**：制作一支【时长和画幅】的动画，看起来像【一种材质或风格】。整支片只按一条规则动：【一种反常的动作】，【角色和转场】也都遵守它。
- 最"重"的玩法（@anabology）：先用生图/生视频模型（fal 上的图像模型 + Seedance）做角色设定图、场景和底片，**再用 JS 在上面重绘一层**（类似转描），成片里甚至看不到底片；还用 ElevenLabs 做音效。
