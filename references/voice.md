# 配音（旁白）

**什么时候配**：按可哥对这个项目的偏好。国学系列默认配女声旁白；其他片子默认不配，用中文字幕讲清楚。拿不准就在第一轮问题里问一句。
已跑通的方案是火山引擎 **seed-audio-1.0**：一次生成整段旁白，提示词里写音色人设、整体情绪曲线和逐句的语气，返回**逐字时间戳**。画面上的所有落点都挂在「第 i 句第 n 个字」上，换一条配音只要重新对齐，分镜不用改。

## 1. 流程
```
台词.json ──narr.py──▶ 旁白.wav + .sub.json ──align.py──▶ voice.json ──▶ 画面（字幕、落点）
                                                                     └──▶ mixbgm.py（旁白 + 配乐压低 + 音效）
```
1. **写台词表** `voice/lines_<集>.json`（格式见 `tools/narr.py` 文件头）：
   - `theme`：这是什么片 + **整体情绪曲线**（开头怎样、转折怎样、结尾怎样）；
   - `voice`：音色人设（年龄、性别、嗓音质感、像哪类节目的旁白、语速、留白），省略就用默认的温润女声；
   - `lines`：每句 `[起, 止, 语气, 文本]`。起止秒数是**希望**的位置，模型大致会照着念；语气写具体（「压低声音，像要揭开一个秘密」「像吟诵古文，每个短句之间留气口」）；
   - 数字在台词里写成汉字（念得准），字幕里由 align 按原文显示。
2. **先看提示词**：`python -X utf8 <技能目录>/tools/narr.py 台词.json x.wav --dry`（不花钱）。
3. **生成**：`python -X utf8 <技能目录>/tools/narr.py 台词.json voice/ep01_A.wav`。key 放在项目目录的 `.volc.env`（一行 `VOLC_API_KEY=…`），工具会从台词文件往上找；**key 不进技能目录**。同一段可以生成 A、B 两条挑一条。
4. **对齐**：`python -X utf8 <技能目录>/tools/align.py 台词.json voice/ep01_A.wav ep01/voice.json --offset 1 --width 13`。`--offset` 是旁白在成片里的起点（开头 1 秒封面就写 1）；竖屏每行 11–13 字，横屏 16–20 字。
5. **画面**：字幕卡、逐字出现、关键元素入场都从 `voice.json` 取时间（`lines[i].caps[k].words[n].t`）。
6. **混音**：`bgm.json` 里加 `"voice": "voice/ep01_A.wav", "voice_offset": 1, "voice_json": "ep01/voice.json"`，`mixbgm.py` 会做高通、压缩、截尾巴、按配乐定电平（`voice_over_db` 默认 +9 dB），旁白说话时配乐自动压低（`duck_db` 默认 7 dB）。
7. **校对**：Whisper 转写一遍，对照台词看有没有念错、漏念（faster-whisper `small`，`language='zh'`，`initial_prompt='以下是普通话的句子。'`）。中文短句错一个同音字常见，听一下没问题就放过。

## 2. 坑
- **假词**：语气描述里用引号写了关键词（如「整个世界」放慢），返回的字幕第一句会混进这些词，每字只有约 40ms，音频里根本没念。`align.py` 只按台词原文逐字匹配，会把它们丢掉；`narr.py` 发现语气里有引号会提醒。
- **尾巴**：最后一句之后常有 3–10 秒多余的重复或呢喃（-23 ~ -35 dB），Whisper 校对时会当幻觉忽略，听不出来但混进片子会有怪声。`mixbgm.py` 给了 `voice_json` 就自动截到最后一句结束 +0.35 秒。
- **并发**：同时请求超过 3 条会返回 429，多条 take 排队跑。
- 一次生成很慢（100 秒旁白要等几分钟），`--dry` 把提示词看对了再发。
- 旁白的时间是**模型决定的**，和台词表里写的起止会有出入：画面一律以 `voice.json` 为准，不要以台词表为准。

## 3. 试音色
要换音色时，用 seed-tts-2.0 的单句接口（`/api/v3/tts/unidirectional`，`X-Api-Resource-Id: seed-tts-2.0`，`speaker` 填音色 ID）把同一句话用 8–12 个音色各念一遍，拼成一支带编号的试听片给可哥挑；挑中的音色 ID 填进台词表的 `speaker`。

## 4. 节拍跟着字走（配音片的画面规则）
- 新元素只在**语义段落的边界**进场，不要一句一个新元素；
- 词还没念到之前，对应的元素完全不可见（不要提前露半截）；
- 一段的最后一个落点离镜头切走 ≥ 0.7 秒；
- 字幕卡按 `caps` 出现，逐字跟 `words[n].t`；字高按 `composition.md` §3。

## 5. 不用火山时
lemo-opuscar 自带免费方案：中文 edge-tts（联网）+ Kokoro（英文、离线）+ Whisper 自动校对（`$LEMO/core/tts/`，装 `requirements-voice.txt`）。音质和情绪控制不如 seed-audio，适合试做和英文片。
