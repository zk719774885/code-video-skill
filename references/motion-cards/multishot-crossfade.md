# 多镜头 2D 合成叠化
- 一句话意图：多个 3D 场景（不同场景、不同机位）之间平滑叠化，字幕、HUD、颗粒画在同一张 2D 画布上，全片质感统一。
- 适合：Three.js 多场景片。不适合：单场景片（直接 R3.render）。
- 参数表：
| 参数 | 值 | 说明 |
|---|---|---|
| 叠化时长 `xin` | 0.3–0.6 s，smoothstep | 叠化时同一帧渲两次 3D，别太长 |
| 镜头重叠 | 后一镜头 `a` = 前一镜头 `b` − xin | |
| WebGL 画布 | `opacity: 0`，只当离屏渲染器 | 真正显示的是 2D 画布 |
| 常驻浮尘 | 300–420 个 Points 挂在 camera 上 | 所有镜头都有，画面一直在呼吸 |
- 声音：叠化处一个轻 whoosh，或下一镜头的环境声提前进来（J-cut，`../directing.md` §6）。
- 已知坑：灯光强度见 `../three.md` 光强参考值（初值 500–1300 会全片过曝）；按帧号取颗粒贴图要正模（`--mb` 时 t 可能为负）。
- 参考实现：`templates/three-multishot/index.html`（`SHOTS`、`draw3D`、`render`）。
- 验收记录：QWERTY 冷知识 11 个镜头（2026-10-23）。
