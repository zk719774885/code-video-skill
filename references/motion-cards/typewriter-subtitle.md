# 逐字字幕 + 英文副行
- 一句话意图：中文字幕一个字一个字浮现，关键词高亮，下面跟一行小号英文斜体——爆款知识片的标准字幕。
- 适合：所有无配音知识片。配音片改成按字级时间戳出现。
- 参数表：
| 参数 | 值 | 说明 |
|---|---|---|
| 中文 | Noto Serif SC 600，字高按 `../composition.md` §3（横屏 ≥ 54px） | `{}` 包住的词用金色 #f0c06a |
| 逐字速度 | max(16, 字数 / 1.1) 字/秒 | 每字 0.09 s 淡入 + 上移 6px |
| 英文副行 | Georgia italic 25px（横屏），透明度 0.82 | 中文打到 60% 时 0.5 s 淡入 |
| 阴影 | rgba(0,0,0,.75) blur 14 | 浅底画风改成浅色描边 |
| 停留 | 打完后 ≥ 字数 ÷ 4.5 + 1.5 s | `../directing.md` §7 |
| 退场 | 最后 0.35 s 淡出 | |
- 声音：通常不配；打字机题材可配极轻的键声。
- 已知坑：字幕太小（《此心光明02》竖屏约 50px，被评为读不清）→ 竖屏 ≥ 60px；QWERTY 横屏用的 46px 字号按新规则也偏小，新片横屏字号 ≥ 58px；字幕压在主角身上 → 主角构图时预留字幕带。
- 参考实现：`templates/three-multishot/index.html` 的 `drawSubs` 和 `SUBS`（`{}` 高亮语法）。
- 验收记录：QWERTY 冷知识（2026-10-23）。
