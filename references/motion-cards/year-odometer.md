# 年份滚轮
- 一句话意图：每一幕开头告诉观众「现在是哪一年、在哪里」，滚动的数字本身就是时间流逝的动画，贯穿全片做时间锚。
- 适合：历史、人物传记、技术演进、知识片（爆款《运气的形状》《opus家族史》都在用）。不适合：没有时间线的题材。
- 参数表：
| 参数 | 值 | 说明 |
|---|---|---|
| 位置 | 左上角，x≈92、y≈78（1080p 横屏） | 竖屏放顶部安全区下方 |
| 字 | Georgia 700 60px，金色 #efc777 | 每位一个裁切窗 44×66 |
| 滚动时长 | 1.1 s，`inOutCubic` | 每位错峰 0.08 s，高位多转几圈（转数 = 3 − 位序） |
| 地点小字 | 17px 字距 4px，滚完 0.6–1.2 s 内淡入 | 下面一条细线 |
| 出现 | 首个年份前 0.3 s 淡入 | 之前不显示「0000」 |
- 声音：滚动时一组轻的 tick（每位落定一个），落定那一下可加一声低沉的木质 thump。
- 已知坑：首个年份出现前会露出「0000」→ 先淡入再滚；年份地点小字要 ≥ 辅助字高（`../composition.md` §3）。
- 参考实现：`templates/three-multishot/index.html` 的 `drawYear` 和 `YEARS`。
- 验收记录：QWERTY 冷知识（2026-10-23，可哥认可发抖音）。
