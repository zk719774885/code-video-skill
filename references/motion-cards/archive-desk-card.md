# 档案卡片落桌
- 一句话意图：真实的老照片、专利图、古籍书影做成书桌上的实物卡片，抛物线滑入落桌，史料一下子变得可信、有质感。
- 适合：历史、人物、发明、国学（古籍刻本、画像）。素材来自 `tools/assets.py`（Commons 公有领域）。
- 参数表：
| 参数 | 值 | 说明 |
|---|---|---|
| 调色 | `assets.py grade duo`（照片）或 `ink`（线稿、刻本） | 不同来源放在一起才统一 |
| 卡纸 | 米黄 #e6dbc2 + 边缘做旧渐变 + 5000 个斑点；四周留边 5.5%、底边 12% | 底边写 Courier 说明文字 |
| 卡片 | 薄 Box 厚 0.03，图贴 +y 面（材质数组第 3 个） | 投影、接受阴影 |
| 入场 | 1.15 s，`outQuart`；高度 sin 弧最高 0.9；旋转 0.55 rad 归零 | 抛物线滑入 |
| 光 | SpotLight 跟随相机目标点，浅景深 | 主角被照亮（`../composition.md` §2） |
- 声音：落桌那一刻配 `paper` 或 `stamp`。
- 已知坑：白底博物馆照片直接平铺很突兀 → 放进卡片里就不违和；卡片太小会变成空场 → 特写时卡片 ≥ 1/3 帧高。
