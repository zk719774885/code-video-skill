# 方块砸字 + 子弹时间
- 一句话意图：几百个刚体方块倾泻砸在 3D 字上，中途时间几乎停住、方块悬在空中，再恢复——一眼「这是真物理」的招牌镜头。
- 适合：片头、炫技、品牌落版。2–5 秒，全片一次。
- 参数表：
| 参数 | 值 | 说明 |
|---|---|---|
| 方块 | 550 个，0.28 × 0.6–1.4 倍，倒角 0.025 | 八成落在字后面，前景留给字 |
| 子弹时间 | 物理 time_scale：0.5 s 起减速，0.8 s 到 0.12×，2.4 s 起加速，3.0 s 回到 1× | 要卡在下落途中 |
| 渲染 | Cycles + OptiX，景深 f/2.8 对焦在字上，运动模糊 0.5 | |
| 机位 | 慢推 + 轻微下降，Track To 字中心 | |
- 声音：方块落地一片碎响，慢动作期间抽掉环境声只留低频嗡鸣，恢复时一声 impact。
- 已知坑：慢动作放在落地之后就看不出来；1080p 64 采样很慢，先渲 10 帧测速。
- 参考实现：`templates/blender-smash/scene.py`，说明见 `../blender.md`。
- 验收记录：技能样片（2026-10-23）。
