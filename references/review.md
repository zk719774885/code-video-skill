# 独立评委：交付前让另一个 AI 打分，改一轮再评

自己做、自己查有确认偏差。每支片在交给可哥之前，开一个**干净上下文的 subagent** 当评委，按下面的维度打分、给带时间码和数值的修改清单；按清单改一轮、再评一次，**首检永远不交给可哥**。
评分维度和锚点改编自 [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15) 的 `rubric.md`（MIT License, Copyright (c) Vincentwei1021），按我们的片种和可哥的偏好调整。

## 1. 给评委准备材料（制作对话里做）
```
python -X utf8 <技能目录>/tools/contact.py 成片.mp4 --every 0.5 --cols 8 --w 240 --out review/sheet.jpg     # 每 0.5 秒一帧（长片会分成几张）
python -X utf8 <技能目录>/tools/contact.py 成片.mp4 --from 高光前1s --to 高光后1s --every 0.1 --cols 10 --out review/hero_strip.jpg
ffmpeg -ss <t> -i 成片.mp4 -frames:v 1 review/key_<t>.png          # 5–8 个关键时刻的原尺寸帧（开场 0.5s、封面、每段高光、结尾）
python -X utf8 <技能目录>/tools/frame_metrics.py 成片.mp4 --sub <字幕带> > review/metrics.txt
ffmpeg -i 成片.mp4 -af ebur128=peak=true -f null - 2> review/loudness.txt   # 只留最后的 Summary
ffmpeg -i 成片.mp4 -vf blackdetect=d=0.2 -an -f null - 2> review/black.txt
```
再附上：`TREATMENT.md`（或至少一句话梗概、风格名、目标平台和画幅）、`references/composition.md`。

## 2. 召唤评委（用 Agent 工具，general-purpose，不要用 fork）
把下面这段作为 prompt，替换尖括号里的内容。评委只读文件、不改任何东西。

```text
你是资深动态设计评委（Buck / ManvsMachine 级创意总监，同时熟悉抖音、B 站头部设计账号）。这支片不是你做的。
请严格、具体地评，目标是让它达到「高端商业 / 获奖」水准。客气没有用，具体才有用。

片子：<成片路径>，<横屏/竖屏>，目标平台 <抖音等>。风格：<风格名 + 风格卡路径（如 lemo 的 STYLE.md）>。
创意方案：<TREATMENT.md 路径>。构图规则：<技能目录>/references/composition.md。
审片材料在 <review 目录>：sheet*.jpg（每 0.5 秒一帧）、hero_strip.jpg、key_*.png（原尺寸）、metrics.txt、loudness.txt、black.txt。
需要更多帧就自己用 ffmpeg 从成片里抽。原尺寸帧要放大看细节：边缘、锯齿、色带、字体回退（豆腐块）、裁切。

1. 规格：时长、分辨率、帧率；响度约 -14 ~ -16 LUFS、真峰值 ≤ -1 dBTP；没有意外黑帧和意外静止段；关键画面和音乐重拍对齐。
2. 按 7 个维度各打 1–10 分（5 = 合格的学生作业；6 = 不错的模板水准；7 = 扎实的专业水准；8 = 高端代理公司；9 = 获奖入围；10 = 世界最好）。
   大多数首版应在 5–7 分，不要虚高。
   - 风格还原：一眼认得出这个风格；风格卡里的标志性特征和技法都在、都对
   - 创意与惊艳：有清楚的点子；前 3 秒有钩子；有一个让人记住的高光时刻；结尾画面令人满足并呼应开头
   - 动效：缓动、间距、重叠、预备和跟随、弧线、转场、运动模糊；没有死板或抖动的运动；没有「入场即停」「落位即切」
   - 版式与构图：每镜一个主角且 ≥ 1/4 帧高、层级、网格、中文排版、配色、留白；字幕按 composition.md 的字高够大
   - 质感：光、材质、纹理、颗粒、发光、细节与风格相称；主角被照亮；没有色带、锯齿和穿帮
   - 声音：配乐气质对、音效和画面动作同步且有材质感、混音和响度；重击没有「双响」
   - 技术：规格达标、字体加载正确、没有闪烁、裁切和跳帧
3. 给 5–10 条修改，按对最终观感的影响排序。每条写：时间码；看得见的问题；为什么重要；具体怎么改（技法和数字：缓动曲线、帧数、像素、颜色、字号、布局）。
   宁可少而大，不要一堆小毛病。至少一条是提升惊艳度的，不只是打磨。
4. 列出「严重问题」：任何看起来像通用 AI 模板的东西、不自然的中文文案、字体回退或豆腐块、规格不达标、空场、字幕太小读不清。
返回：评分表、严重问题、修改清单。用中文。
```

## 3. 按评审改一轮（回到制作对话）
- 先把当前成片和源码存成 v<N>（复制一份），不要在原版上直接覆盖。
- 严重问题和高影响的修改全部落实；有更好的方案可以替换，但要说明理由。评委说是优点的地方不要改坏。
- 重新渲染原尺寸、重跑 metrics 和响度，自己看帧确认改到位了，再**用新的干净 subagent 评第二次**（不要把第一次的评审给它看）。
- 两次分数和改了什么写进项目的 `REVIEW.md`；交给可哥时附一句「评委两轮分数：x → y，主要改了……」。
- 目标：每个维度 ≥ 7，至少两个维度 ≥ 8。达不到的维度在交付时说明原因。
