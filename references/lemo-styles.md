# lemo-opuscar 风格目录（157 种）

来源：[lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar)（MIT，作者 Lemomo），本机装在 `D:\AI\claude视频制作\lemo-opuscar`（下文记 `$LEMO`）。在线画廊：https://lemomo-ai.github.io/lemo-opuscar/

两套资源：

- **59 种完整风格**：每种有风格卡 `$LEMO/styles/<目录名>/STYLE.md`（材质、配色、字体、运动、镜头语法、声音调色板、独有招式、坑、变化空间）+ 示例片源码 `demo/`。用户按中文名或英文名点名，到这里查目录名。
- **98 种 OPUSCAR 98 风格**：来自特别放映片《OPUSCAR 98》，每部奥斯卡最佳影片一种画风（2D 77 / 2.5D 4 / 3D 17）。只有风格提示词、融合来源、分镜和导演说明（`$LEMO/styleboard/opuscar98_styles.json` 里按 `no` 查 `prompt_zh` / `blend_zh` / `shots` / `direction_zh`），**没有源码**，按提示词从零写。

用法见 SKILL.md「引擎四：lemo-opuscar」。
